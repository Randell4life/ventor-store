# VENTOR — დამოუკიდებელი ონლაინ მაღაზია

ეს არის Laravel 13 + Filament 5 პროექტის საწყისი კოდი. პროექტი MotoHub-ისგან დამოუკიდებელია.

## მოთხოვნები
- PHP 8.3 ან უფრო ახალი
- Composer
- Node.js 20.19+ ან 22.12+
- MySQL ან MariaDB (SQLite-ზეც შესაძლებელია `.env`-ში შესაბამისი კონფიგურაციით)

## ინსტალაცია Windows / PowerShell

```powershell
cd C:\პროექტის\გზა\ventor-store
composer install
Copy-Item .env.example .env
php artisan key:generate
```

`.env` ფაილში მიუთითეთ მონაცემთა ბაზის პარამეტრები და ადმინისტრატორის მონაცემები:

```env
VENTOR_ADMIN_EMAIL=თქვენი-ელფოსტა
VENTOR_ADMIN_PASSWORD=ძლიერი-პაროლი
```

შემდეგ:

```powershell
php artisan migrate --seed
php artisan storage:link
npm install
npm run build
php artisan serve
```

საიტი: http://127.0.0.1:8000  
ადმინისტრაცია: http://127.0.0.1:8000/admin

**უსაფრთხოება:** პირველი გაშვების შემდეგ შეცვალეთ საწყისი ადმინისტრატორის პაროლი. არ ატვირთოთ `.env` GitHub-ში.

## რა შედის
- ქართული, responsive storefront;
- კატეგორიებისა და პროდუქტების მონაცემთა მოდელები;
- კატალოგი, ძიება და ფასით დალაგება;
- შეკვეთის შენახვა ბაზაში და მარაგის შემცირება ტრანზაქციაში;
- Filament admin panel-ის ავტორიზაციის საწყისი კონფიგურაცია;
- საწყისი კატეგორიები და არააქტიური დემო პროდუქტები.

## მნიშვნელოვანი შეზღუდვები ამ ვერსიაში
- ეს არის სამუშაო საწყისი პროექტი და არა დასრულებული კომერციული მაღაზია.
- რეალური გადახდის პროვაიდერი, მიწოდების ტარიფები, SMS/email შეტყობინებები, სრული Filament CRUD რესურსები და რეალური ICECO კატალოგი ჯერ დასამატებელია.
- დემო პროდუქტები არააქტიურია და არ ჩანს მომხმარებლის კატალოგში.
- რეალური პროდუქტის ფასები/ფოტოები/მარაგი არ არის გამოგონილი.
- შეკვეთის ფორმა ამ საწყის ვერსიაში ითხოვს პროდუქტის ID-ს; შემდეგ ეტაპზე უნდა დაემატოს სრულფასოვანი JavaScript კალათა.
